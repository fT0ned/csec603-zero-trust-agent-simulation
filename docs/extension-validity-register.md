# Extension validity register

Written during the frozen full collection. This is interpretation/quality documentation; it does not change samples, conditions, hypotheses or frozen code.

| ID | Evidence or assumption | Consequence / reporting rule |
|---|---|---|
| V01 | Real pilot: 0/120 exact payload follows; only 41 payload-bearing brief reads | Report ITT and exposure separately. Do not call an unattempted attack prevented, or infer broad model robustness. No stratum qualified; no extra coercion sampling. |
| V02 | Qwen3B neutral pilot: 38 invalid-authority attempts overall across pilot, nine unauthorized writes in six runs; five false coercion labels from benign-data reuse | Unrelated task drift is distinct from payload coercion. Provenance correlation is not causal attribution; natural-model sensitivity is not estimable without positives. Full scripted accuracy is a separate evidence class. |
| V03 | Four models represent three families; commercial OpenAI snapshot is the requested mini model, not a current frontier model | Do not claim complete frontier replication or rank models. DeepSeek remains a mutable alias. Local model digests pin weights, not deterministic CUDA execution. |
| V04 | Temperature 0, small fixed business fixtures and repeated scripted actions | Wilson intervals and exact McNemar/Holm describe the controlled matrix; effective diversity is lower than run count. Repeated-run p-values do not establish population-level independent evidence. |
| V05 | One PC, Docker/WSL2 and fixed front/control/tools boundaries | Call it network-separated, not multi-host. No enterprise latency/SLO, scale, cross-machine clock or production fault-domain claim. Model blocks are temporal, not randomized performance comparisons. |
| V06 | C2-E uses a new Python PDP; C1-E uses an STS bearer capability derived from SPIRE admission; every condition has shadow audit instrumentation | These are functional extension conditions, not exact original C0/C1/C2 replications. Bundled effects cannot identify each mechanism's marginal contribution. Original 0% baseline attribution is not comparable to the new fully instrumented baselines. |
| V07 | Synthetic human grant, trusted STS/PDP/host, UID workload attestation, fixed expected peer mapping | No human IdP consent, hardware/software integrity attestation, compromised control plane, stolen signing key, same-origin attacker or benign peer migration evaluation. IP mismatch is a laboratory signal, not sufficient enterprise proof of impersonation. |
| V08 | Experimental PoP profile: HTTP inside private networks, custom exchange API, ephemeral proof cache; no mTLS | Not full RFC 9449/OAuth deployment conformance. Restart durability, proxy behavior and nonce-endpoint denial-of-service resistance are not established. |
| V09 | Recovery forces a fresh same-subject SVID using an auxiliary audience to bypass SPIRE caching, then new capability/key binding | This tests re-admission mechanics. It does not prove eradication of a compromised process or a production identity-recovery procedure. Re-attestation is UID-based. |
| V10 | The benchmark invokes reissue/rebinding even after identity-preserving PAA responses | For those cases no outage exists to recover from; the reported time is optional reset-path overhead, not observed downtime. Uniform-suspension recovery also assumes immediate operator action, without human IR delay. |
| V11 | Availability is a scripted owner probe; task completion checks expected executed calls, separately from unauthorized effects | Credential availability is not business-task success. Functional completion can coexist with extra unsafe effects. Unauthorized-effect endpoint counts durable writes; invalid-authority reads are separately attempted actions, not a comprehensive confidentiality-loss measure. |
| V12 | E4 replay observes one token-only attempt and a five-second post-attack interval | It is a shortened first-use mechanism replication, not the original expiry-window Part C. No new exposure-to-expiry distribution is measured. |
| V13 | Finance, CRM handoff and file administration use existing private mock apps; no live SaaS/admin estate | Workload/authority-structure diversity is broader than one objective but remains synthetic and narrow. No external targets, real email or money movement. |
| V14 | Approval grid uses assumed delays, timeout, abandonment, rubber stamping and fatigue; live intent gate remains deterministic | Standalone simulated behavior is not a measured human approver or an integrated production queue. Aggregate grid rates are consequences of selected parameters. |
| V15 | Clock monitor and one linked timestamp/infrastructure rerun rule; resource observer every ~30 seconds | Preserve originals/sensitivity. Observer frames are not independent runs. HTTP action timing excludes nonce fetch/signing; signing is separate. PDP/dispatch timing includes tool/audit work. Host event-response and revocation timings are conservative roundtrip upper bounds. |
| V16 | Token-rate calculations and retained uncertain reservations; source/rule counts and audit-byte measurements | No account-balance reconciliation, electricity cost, human policy-administration effort, end-user incident-response time or economic ROI estimate. |
| V17 | Pilot app-404 bug, four early-terminated units retained, one controlled interruption/rerun, later UTF-8 and recovery-cache fixes | Pilot is exploratory and mixed-version. Do not imply source-identical whole-pilot reproduction from the final freeze. Payloads/prompts/selection did not change; full collection has its own immutable source/runtime/config gate. |
| V18 | Runtime local context observed at 4,096 tokens for both Qwen models, despite 32K architectural metadata | Report actual context. It was a pinned-server/hardware default, not an explicit per-request context setting; cross-hardware exact behavior is not guaranteed. |
| V19 | Accounting gap/tamper confidence is injected by the trusted test API; original hash-chain tests separately verify alteration detection | PAA tests response selection given signals, not autonomous audit-anomaly detection accuracy or truthful logging after logger compromise. |

All limitations remain even when a control has zero observed failures. Recommendations are architectural and operational tests to perform, not a claim that this prototype is ready for production.

V20 — Confirmed post-freeze deterministic counterexample: Python equality for approved intent and raw JSON usage keys disagree for25 versus25.0. The frozen gate and reused oracle can both miss a semantic duplicate. A3 is not universally satisfied; registered full results apply to tested representations. A new unit-tested normalization helper is engineering-only and is not retroactively installed or pooled into the study.

V21 — Post-freeze deterministic URI-normalization counterexample: encoded trailing dot `/a/%2e` becomes `/a` instead of `/a/`. Frozen fixed `/tool` measurements are unaffected by this variant, but full RFC3986/RFC9449 normalization compliance is not established. No repair is installed. See docs/extension-uri-edge-case.json and RFC3986 DOI10.17487/RFC3986.

V22 — E3 old-token probe uses the current rotated key. For bound tokens a refusal can therefore reflect key-binding mismatch as well as revocation; do not infer isolated revocation effectiveness from that probe. Bearer recovery probes and unit regressions separately exercise revoked-credential denial.

V23 — E1 exact-action/parameter follow endpoint is intentionally strict and can miss partial or inexact harmful influence. Nine pilot unauthorized writes are therefore reported separately, and neither exact-match nulls nor task drift establish the absence/presence of all possible coercion mechanisms.

V24 — Full E2 positive exchanges inherit equal scope/budget at A and B; they test non-widening, not a strictly smaller grant at every hop. Strict narrowing (root10→A5→B2) is covered by the pre-freeze unit test test_signed_attenuation_chain_forgery_truncation_cascade, not by an added sampled network arm. Widening is attempted and rejected separately at A/B.
