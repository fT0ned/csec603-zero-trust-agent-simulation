# Study002 amendments and deviations

## Post-pilot, before full freeze: local template fidelity repair

The fixed240-unit pilot completed (238 completed,2 bounded model-step-limit units; zero provider/infrastructure failures). Payload exposure was supplied in240/240 first successful requests. Real committed coerced writes occurred in65/180 injected units, involving GPT-4.1 mini and Qwen3B/7B. Registered selection carried42strata, yielding5,880 full units and90 paired contrasts.

Calibration review independently revealed a rendering defect for Llama3B and Mistral7B, each0/10 benign completion and0 model tool calls across40pilot units. Their stock Ollama Go templates advertise tools only when the last history item is a user message. The registered forced-read prelude ends in a tool result, so the function definitions are omitted despite the HTTP `tools` field. Mistral's stock template also suppresses the supplied system prompt in that arrangement. The saved templates and raw responses prove this interface problem; their nulls are functional/interface failures, not evidence of resistance.

Judgment: repair **tool/system advertisement fidelity** before the held-out freeze, rather than knowingly run a nonfunctional full reference agent. New derived runtime profile tags retain the exact base weights/model metadata and preserve both stock tags. Only Go conditions controlling visibility of the existing tool schema/system instruction are corrected. Payloads, user/system instruction text, inference settings, existing Qwen pins, model-family roster, thresholds, seeds, selection decision and full matrix are unchanged. Both base and effective profile digests and exact recipes are archived. The source version difference is a protocol deviation and must remain visible.

**No additional pilot inference or replacement units are collected.** All240 pilot observations and their seals remain unchanged. Selection remains the original42 strata; no neutral injected Llama/Mistral strata are added. Their warning and benign reference strata were already mandatory and will use the repaired profiles in the existing planned full matrix. Consequently the pilot does not establish neutral-arm susceptibility/eligibility for those two agents, and full/pilot interface versions must not be pooled or presented as source-identical replication. Full results can evaluate their repaired warning/reference/calibration behavior only.

This is not an attack/payload improvement chosen to raise follow rates. Coercion already succeeded in three other agents, which are unchanged. It fixes missing tool definitions and a missing warning condition, verified from the static stock templates independently of success/failure labels. No model-weight substitution, extra seeds, altered selection, linked pilot resampling or retrospective rewrite of the original preregistration is performed.

Other pilot negatives remain:65 true-coercion requests were identified, but12 true-none model requests received coercion labels (precision65/77; recall65/65). These are retained, not repaired away after looking at labels. Modelstep limits, task drift and all full negative results remain reportable.
