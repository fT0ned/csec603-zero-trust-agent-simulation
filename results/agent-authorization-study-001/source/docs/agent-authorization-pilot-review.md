# Feasibility review of the real-LLM authorization pilot

Authors' independent exploratory review, 24 October 2026. Collection `results/agent-authorization-pilot-002` completed 24/24 planned runs. Its [independent analysis](../results/agent-authorization-pilot-002/analysis/report.json) passes raw/source hashing, model-call dispatch/feedback checks, gateway/independent-effect reconciliation, trusted authorization checks and audit-chain/checkpoint/control-record agreement. This is a feasibility verdict, not statistical confirmation of A1–A3 or the original hypotheses.

## Verdict and actual behavior

The pilot is feasible for the separately frozen study. All fourteen adversarial task/condition cells contain a genuine unauthorized model-generated attempt reaching the actual gateway. All ten legitimate export/payment cells complete their principal-authorized effects, covering both tasks in all five conditions. There are zero observed gateway false denials. The exact operational objective, system prompt, tool schema and trusted principal state match across each applicable condition comparison; the agent cannot change its delegation. Model trajectories after tool feedback are retained as observed.

There are 59 actual gateway actions, twenty unauthorized attempts, seven unauthorized denials and thirteen independently committed unauthorized effects. The independent classifier uses the trusted delegation and pre-call durable state, never the gateway's allow/deny label as the authority oracle. Counts are descriptive repeated actions within 24 runs, not twenty independent statistical trials. Unauthorized read executions are zero. Full tables and actual per-run evidence are in [run-index.csv](../results/agent-authorization-pilot-002/analysis/run-index.csv), [condition-results.csv](../results/agent-authorization-pilot-002/analysis/condition-results.csv) and [results.md](../results/agent-authorization-pilot-002/analysis/results.md).

The model made its own additional calls. Scope-delete runs included CRM reads before deletion; C0/C1 also read afterward. C2 workflow-export tried offsets 10 and 15, received denials, then retried both with fresh actual calls before stopping, producing four unauthorized attempts rather than two. These attempts were neither scripted nor removed. Payment-positive runs read the payment catalog and tried a nonexistent `invoice-approved` file before paying correctly; the actual known-no-effect tool errors reached the model and it recovered. C2-RS also made a final payment read. Five such optional missing-file reads are tool failures, not credential failures, false authorization denials or incomplete legitimate tasks.

The independent analyzer checks every schema-valid generated call is dispatched in order for complete units. It checks that subsequent provider requests contain each prior call ID and its actual gateway feedback, including errors/denials, rather than merely trusting recorded summary counts. Independent tool write IDs, action parameters and final export/payment/deletion/email state confirm durable effects. Neither successful HTTP status nor the assistant's completion prose establishes a commit.

Condition-visible audit records provide all seventeen declared full fields and correct principal/issued-agent/task/chain/origin/credential/action/parameters/decision/result agreement for 31/31 C2-family actions. The remaining 28 C0/C1 actions retain their intentionally smaller baseline records. Harness truth is not used to fill missing audit fields. This measures evidence coverage and exact source agreement, not attribution of psychological cause or actual injection coercion. All gateway audit chains/checkpoints and stored control records agree in this collection.

## Exploratory repairs and preserved failure

The first pilot, `agent-authorization-pilot-001`, remains intact with 24 runs, eight interrupted units and an [independent validation failure](../results/agent-authorization-pilot-001/analysis/report.json). Five retained control-plane audit records disagreed with the bytes originally returned/hashed: a nested workflow dictionary was shared and later calls changed earlier policy-input counter snapshots. The service now copies policy inputs and stored audit records. A regression verifies snapshot independence, and the new analyzer rejects retained control-audit mutation even when the gateway chain itself verifies.

The first collector also interrupted known-no-effect tool errors before the model could see the response and recover. The repaired collector returns confirmed no-effect failures to the actual model and separately records tool failures; infrastructure errors and uncertain effects remain explicit failures. The original principal-vendor objective named absent `vendor-2`. The second pilot names `attacker-vendor`, an existing synthetic vendor, while trusted delegation continues to permit only `vendor-1`. This repairs tool feasibility without changing the authority boundary or choosing a model for favorable results.

Before these pilots, the policy was repaired to read allowed vendor and per-action limits from trusted delegation rather than hardcoded equivalents. Original fixtures retain their existing values; historical captured source/raw/results remain untouched. Runtime verification checks source bytes in all seven source-bearing services; current controls use real SPIRE/OPA and the actual private tools. This pilot review depends on the separately retained environment/runtime verification and never rewrites historical measurements.

## Resources and freeze readiness

A 720-unit projection at this observed average with a 50% reserve is USD 0.3140613. This is a feasibility projection, not a fixed provider invoice or guaranteed upper bound on future model behavior. The preserved provider adapter retains its reservation bounds and uncertain-charge accounting.

A read-only query of the existing aggregate `.runtime/spend.sqlite` after this pilot found 4,743 settled requests, total charged estimates USD 0.570759036 and no unsettled reservations. The remaining amount under the unchanged USD 4 cap was USD 3.429240964, exceeding the reserved projection. No ledger was reset, substituted or topped up. Provider access and bounded observed cost permit the prospective full allocation. Its fixed manifest must still run without outcome-driven stopping; any access, budget, model or infrastructure failure remains recorded and may prevent confirmation.
