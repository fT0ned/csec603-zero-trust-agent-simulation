# Descriptive enforcement figures

Each collection/mode/scenario has separate SVG/PDF/PNG exports. Rates and Wilson intervals are copied from the independently reconciled descriptive report without pooling or reanalysis. S5 supplemental intent is separate from primary chained-total success; Not measured means no endpoint observations, not zero.

`endpoint-rates.csv` retains full stratum identifiers, numerators, denominators and intervals. `descriptive-run-metrics.csv` preserves distributions of within-run median/p95 action and authorization times, workflow ratios/totals, reachable authority and approval burden. These distributions are not call-level independent observations. `figure-manifest.json` pins the consumed reports, plotting script and exported artifacts.

LLM pilot figures are exploratory; scripted figures are engineering checks and cannot be presented as measured natural model susceptibility. Raw data and original study reports remain separate.
