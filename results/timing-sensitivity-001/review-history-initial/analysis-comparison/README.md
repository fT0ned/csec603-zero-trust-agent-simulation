# Original versus conditional timing amendment

Original collection: quality veto retained; raw analyzer judgments are not accepted confirmatory claims

Amended collection: conditional amendment only; requires independent quality acceptance and preserves original veto

All contrasts are retained in a full outer join, including unmeasured and unmatched entries. CSV columns preserve original/amended effect estimates, confidence bounds, sample counts, p-values, Holm adjustments, methods and raw judgments. Missing sides are blank/null, never zero. `comparison.json` preserves complete source rows and report hashes, eligibility diagnostics and wrapper quality labels. No statistical procedure is rerun.

Use only after actual replacement data and independent quality review. A supplied quality-review file is pinned for traceability; the helper does not infer that its contents approve the amendment. Original unqualified analyzer support labels remain quality-vetoed. The amendment is conditional and cannot retroactively fix the original collection.
